# FreeStream

Stream movies, TV shows, and anime from your terminal.

## Install
    pipx install freestream
    uv tool install freestream
    pip install --user freestream

## Run
    freestream

Auto-installs Playwright, static-ffmpeg, and remaining dependencies on first launch.

## Features
- Movies, TV, Anime via TMDB
- vidfast.pro, vidsrc family, peachify
- OpenSubtitles auto-fetch
- yt-dlp + ffmpeg downloads
- Windows, macOS, Linux, WSL, Termux
